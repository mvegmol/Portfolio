# Miguel Vega Molina - Portfolio Personal

Este es un portfolio personal desarrollado con Next.js 15, React y TailwindCSS, diseñado para mostrar mi experiencia, habilidades y proyectos como Ingeniero Informático en Sistemas de Información

## Características

-   Diseño moderno y responsive
-   Animaciones fluidas con Framer Motion
-   Formulario de contacto funcional con EmailJS
-   Secciones personalizables
-   Rendimiento óptimo

## Secciones

-   **Hero** - Presentación personal con información de contacto
-   **Sobre Mí** - Información detallada sobre mi perfil profesional
-   **Experiencia** - Historial laboral y educación
-   **Proyectos** - Showcase de proyectos destacados
-   **Habilidades** - Conocimientos técnicos organizados por categorías
-   **Contacto** - Formulario de contacto y datos personales

## Tecnologías Utilizadas

-   Next.js 15
-   React 19
-   TailwindCSS 4
-   Framer Motion
-   EmailJS
-   React Icons

## Configuración del Formulario de Contacto

Para hacer funcionar el formulario de contacto, debes configurar EmailJS:

1. Crea una cuenta en [EmailJS](https://www.emailjs.com/)
2. Configura un servicio de correo electrónico (Gmail, Outlook, etc.)
3. Crea una plantilla de correo electrónico
4. Obtén tus IDs de servicio, plantilla y usuario
5. Actualiza estos IDs en el componente `Contact.tsx`
